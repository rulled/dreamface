DreamFace Batch Assistant Privacy Policy

Last updated: April 8, 2026

DreamFace Batch Assistant is a browser extension for batch preparation and submission of audio-driven video generation tasks on DreamFace.

What the extension does

The extension helps a user select DreamFace items on the page, attach local audio files, optionally normalize or split those files in the browser, submit jobs to DreamFace, monitor progress, and help with downloading generated results.

What data is processed

  • DreamFace page content required to identify user-selected videos, queue state, creation cards, and status messages.
  • Local audio files that the user explicitly selects.
  • Temporary run state, queue metadata, and temporary processed audio blobs stored locally inside the browser extension.

How data is used

  • Selected audio files are processed locally in the browser to validate duration, pad short clips, or split long clips when required.
  • Processed files are uploaded only to DreamFace as part of the user-requested automation flow.
  • Temporary queue state is stored locally to support long-running jobs and popup reopening.

Data sharing

The extension does not send data to any extension-controlled backend or analytics service. Data is sent only to DreamFace when the user explicitly runs a generation task.

Data retention

Temporary run data and processed audio blobs are kept locally inside the extension only for the duration needed to execute the batch and monitor results. They are not intended for long-term storage.

Permissions

  • storage is used to keep settings and run state locally.
  • offscreen is used to run audio preparation outside the popup so long tasks can continue more reliably.
  • DreamFace host access is used only to automate user-requested actions on DreamFace pages.

No sale of data

The extension does not sell user data and does not use user data for advertising.

Contact

Support: https://github.com/rulled/dreamface/issues

This extension does not use Google APIs. It operates only on DreamFace pages and keeps temporary processing data inside the browser extension.
