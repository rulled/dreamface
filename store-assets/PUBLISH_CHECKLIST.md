# Publish Checklist

- Load the unpacked extension and confirm the popup opens on Chrome 116+.
- Verify scan works on the current DreamFace UI.
- Verify one short audio file is padded correctly.
- Verify one long file is split correctly in `180 sec` mode.
- Verify one long file is accepted or split correctly in `600 sec` mode.
- Verify the queue can finish and the Creations check/download flow still works.
- Verify icons render in the toolbar and the extensions page.
- Upload the extension package zip from `dist/dreamface-v1.1.1.zip`.
- Upload at least one screenshot from `store-assets/screenshots/`.
- Upload `store-assets/graphics/small_promo_tile_440x280.png`.
- Optionally upload `store-assets/graphics/marquee_1400x560.png`.
- Publish a public privacy policy URL using the contents of `store-assets/privacy-policy.html` or `store-assets/PRIVACY_POLICY.md`.
- Set homepage URL and support URL to the GitHub repository if you do not use a separate site.
- If the dashboard asks about data handling, use the answers from `store-assets/STORE_LISTING.md`.
